# Plataforma de Capacitación y Evaluación - ISG Mónica Betancur

Sistema web multicliente (multi-tenant) para entrenamiento corporativo y evaluaciones continuas.

## 🚀 Tecnologías

- **Front-end**: HTML5, CSS3 (Vanilla), JavaScript (ES6+ SPA).
- **Back-end & DB**: Google Apps Script con Google Sheets como API REST.
- **Hosting**: GitHub Pages.

## 📁 Estructura del Proyecto

- `index.html` - Estructura SPA (Login, Dashboard, Video, Evaluación, Modales).
- `styles.css` - Sistema de diseño responsivo con estética glassmorphic.
- `app.js` - Lógica cliente, YouTube IFrame API, motor de preguntas unidireccional y consumo de API.
- `Code.gs` - Código servidor en Google Apps Script para gestionar lectura/escritura en Google Sheets.
